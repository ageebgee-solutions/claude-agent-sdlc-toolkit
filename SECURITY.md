# Security Policy

## What this project is

The toolkit is Markdown files: role prompts in `agents/`, playbooks in `playbooks/`, and documentation. It contains no executable code and no service. The risks are in what the files tell an agent to do, for example a rule that weakens a security gate or an example that encourages hard-coding a secret.

## Reporting a vulnerability

Please report security problems privately. Use either:

- GitHub's **private vulnerability reporting** on this repository (Security tab, then "Report a vulnerability"), or
- Email **bryan@ageebgeesolutions.com**.

Include the file and line, what the problem is, and what it could lead to. Please don't open a public issue for a security problem.

We'll acknowledge a report as soon as we can and keep you posted on the fix. This is a small project maintained by one person, so please allow reasonable time for a response.

## Supported versions

Only the latest release on `main` is supported.
